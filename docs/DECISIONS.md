# RAGGuard — Decision Record

Authoritative record of project decisions. Sections:

1. **Confirmed decisions** (`D-xxx`) — binding. Change only via section 4.
2. **Planned defaults** (`P-xxx`) — the intended approach; may be adjusted in the implementing stage, with the change recorded here.
3. **Unresolved decisions** (`U-xxx`) — deliberately open; resolved in the stated stage and then moved to section 1 or 2.
4. **Changes to previous decisions** — what changed, when, and why.

Do not introduce alternative frameworks, databases, or services without recording the reason here.

| D-022 | 2026-10-12 | **PDF extraction: `pypdf`**, page by page with 1-based page numbers. Resolves U-003. | Pure-Python, no system dependencies, and gives page-level text for citations. OCR is out of scope (see `PROJECT_CONTEXT.md`). |
| D-023 | 2026-10-12 | **Chunking: 180 tokens with 30-token overlap**, measured with the embedding model's own tokenizer; chunks never cross a PDF page boundary; each chunk stores document ID, filename, file type, page number (null for TXT), chunk index, text, character span, and token count. **Default top-k = 4** (request override 1–20). Resolves U-005. | Two layers: similarity filters clearly unrelated questions cheaply; the model catches related-but-unanswered questions that similarity cannot (observed: an unanswerable question scored 0.68).
